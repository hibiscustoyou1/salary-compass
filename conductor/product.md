# 产品背景: WealthTrack (薪资罗盘)

## 产品愿景 (Vision)
为用户提供一个高精度、视觉惊艳的“薪资罗盘”，帮助他们清晰透视个人收入结构、五险二金缴纳详情及长期资产增长趋势。拒绝模糊，追求像素级的财务数据准确性。

## 核心业务逻辑 (Core Business Logic) - ⚠️ 严禁篡改

### 1. 薪资总额口径 (Gross Wage)
-   **公式**: `Global Gross = raw.gross + details.income['伙食补贴']`
-   *注意*: 原始数据库中的 Gross 往往不包含单独发放（翼支付发放）的伙食补贴，计算总包时必须手动修正累加。

### 2. 收入结构四分法 (Income Quadrants)
| 类别 | 包含项目 (Items) |
| :--- | :--- |
| **固定薪资** | 岗位工资 + 月度绩效 + 综合补贴 |
| **绩效奖金** | 季度绩效 + 年度绩效 |
| **补贴福利** | 防暑降温 + 伙食补贴 + 其他工资（加班费） |
| **专项激励** | 人才特区 + 专项激励 |

### 3. 五险二金计算规则 (Social Insurance & Funds)
| 项目 | 个人缴纳 (Personal) | 企业缴纳 (Company) | 总额公式 (Total) |
| :--- | :--- | :--- | :--- |
| **企业年金** (Annuity) | `corporateAnnuity` | **4倍** (个人 * 4) | `个人 * 5` |
| **住房公积金** (Housing) | `housingFund` | **1倍** (个人 * 1) | `个人 * 2` |
| **养老保险** (Pension) | `pension` | *(无数据，暂不计)* | `个人` (暂定) |
| **医疗保险** (Medical) | `medicalInsurance` | *(无数据，暂不计)* | `个人` (暂定) |
| **失业保险** (Unemployment)| `unemploymentIns` | *(无数据，暂不计)* | `个人` (暂定) |

> **重要提示**: 通俗说法中的“六险”通常包含补充医疗、工伤或生育，但当前 Schema 仅支持上述 5 种字段。计算时仅累加现有字段。

### 4. 资产校准 (Asset Calibration)
-   **基准**: 基于 `AssetEvent` 表的 `occurredAt` 字段。
-   **逻辑**: 以 `CALIBRATION` 时间节点为分界线切割现金流，确保资产快照准确。

## 目标用户 (Target User)
-   **企业员工**: 拥有复杂薪资结构（底薪、绩效、奖金、补贴混杂）的用户，通过本系统看清实际到手收入与隐形福利（公司缴纳部分）。
